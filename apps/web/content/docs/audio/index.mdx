Declarative audio synthesis for the web, in `@web-kits/react/sound`. Define sounds as plain objects and play them with a single function call.

<Playground />

## Quickstart

Install `@web-kits/react` with your package manager of choice.

<Tabs items={[
  { label: "npm", value: "npm install @web-kits/react" },
  { label: "yarn", value: "yarn add @web-kits/react" },
  { label: "pnpm", value: "pnpm add @web-kits/react" },
  { label: "bun", value: "bun add @web-kits/react" },
]} />

Define a sound as a plain object and call the returned function to play it.

```ts
import { defineSound } from "@web-kits/react/sound";

const pop = defineSound({
  source: { type: "sine", frequency: { start: 400, end: 150 } },
  envelope: { decay: 0.05 },
  gain: 0.35,
});

pop();
```
