Install `calligraph` with your package manager of choice.

<Tabs items={[
  { label: "npm", value: "npm install calligraph" },
  { label: "yarn", value: "yarn add calligraph" },
  { label: "pnpm", value: "pnpm add calligraph" },
  { label: "bun", value: "bun add calligraph" },
]} />

Calligraph animates with Motion, so it needs `motion` in your project too. See [Requirements](/calligraph/requirements).
