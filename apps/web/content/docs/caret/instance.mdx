---
title: Instance
description: The methods on what caret returns.
---

`caret` returns:

| Method         |                                                   |
| -------------- | ------------------------------------------------- |
| `set(options)` | Change any option. The caret keeps its place.     |
| `destroy()`    | Remove the caret and selection and give the field its own back. |

The measured values are exported too, as `IOS`, `MACOS`, `BLINK`, `FOLLOW` and
`DROP`.
