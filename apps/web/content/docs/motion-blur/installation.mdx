## Entry Points

| Import                        |                                                              |
| ----------------------------- | ------------------------------------------------------------ |
| `@web-kits/motion-blur`       | `motionBlur`, the techniques and `sigmaFor`.                 |
| `@web-kits/motion-blur/react` | `useMotionBlur`, `MotionBlur` and `MotionBlurProvider`.      |
