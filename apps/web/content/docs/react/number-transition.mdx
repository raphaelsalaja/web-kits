A number that animates between values. It formats with `Intl.NumberFormat`, so currencies, percentages, units and every locale work as they do there.

<Example>
  <NumberTransitionExample />
</Example>

```tsx
import { NumberTransition } from "@web-kits/react/number-transition";

<NumberTransition
  value={balance}
  format={{ style: "currency", currency: "EUR" }}
/>;
```

## Transitions

| Transition      | From                                              |                                                                     |
| --------------- | ------------------------------------------------- | ------------------------------------------------------------------- |
| `numericText()` | [`content-transition`](/react/content-transition) | SwiftUI's `.numericText(value:)`, the default. Digits blur and roll. |
| `opacity`       | [`content-transition`](/react/content-transition) | The number crossfades.                                              |
| `interpolate`   | [`content-transition`](/react/content-transition) | A crossfade that also eases colour, size and weight.                |
| `identity`      | [`content-transition`](/react/content-transition) | The number swaps.                                                   |
| `balance`       | [`family`](/react/family)                         | Family's balance. Each digit spins through the digits in between.   |
| `keypad`        | [`family`](/react/family)                         | Family's keypad. Typed digits rise in and the rest slide over.      |

```tsx
import { balance } from "@web-kits/react/family";

<NumberTransition value={total} transition={balance} />;
```

## Props

| Prop         | Type                                           | Default                                                  |
| ------------ | ---------------------------------------------- | -------------------------------------------------------- |
| `value`      | `number`                                       |                                                          |
| `format`     | `Intl.NumberFormatOptions`                     |                                                          |
| `locales`    | `Intl.LocalesArgument`                         | The browser's                                            |
| `transition` | One of the transitions above                   | `numericText()`                                          |
| `animation`  | `"smooth"`, `"snappy"`, `"bouncy"` or a spring | `"smooth"`, or Family's spring for `balance` and `keypad` |

`animation` sets what follows SwiftUI's `Animation`: the width, the digits that slide over, and crossfades. Every other prop goes to the `span` it renders.
