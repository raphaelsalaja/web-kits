---
title: Springs
description: The springs the components run on, as SwiftUI describes them.
---

`@web-kits/react/springs` describes a spring the way SwiftUI does: a response, the period of the undamped spring in seconds, and a damping ratio. Pass one as `animation`:

```tsx
import { fromBounce, spring } from "@web-kits/react/springs";

<NumberTransition value={count} animation={spring(0.4, 0.8)} />;
<TextTransition animation={fromBounce(0.5, 0.2)}>{label}</TextTransition>;
```

| Function                                 |                                                                     |
| ---------------------------------------- | ------------------------------------------------------------------- |
| `spring(response, dampingRatio)`         | `Spring(response:dampingRatio:)`.                                   |
| `fromBounce(duration, bounce)`           | `Spring(duration:bounce:)`.                                         |
| `fromPhysics(mass, stiffness, damping)`  | `Spring(mass:stiffness:damping:)`.                                  |
| `fromSettling(duration, dampingRatio)`   | UIKit's `animate(withDuration:usingSpringWithDamping:)`.            |
| `solve(spring, time, from, to, velocity)`| Where the spring is after `time` seconds.                           |
| `settle(spring)`                         | How long it takes to settle, in seconds.                            |
| `toLinear(spring)`                       | A CSS `linear()` easing and its duration in milliseconds.           |

These are the same springs [Springboard](/springboard/springs) uses.
