Text that animates between strings. Pass the text as its child.

<Example>
  <TextTransitionExample />
</Example>

```tsx
import { text } from "@web-kits/react/family";
import { TextTransition } from "@web-kits/react/text-transition";

<TextTransition transition={text}>{label}</TextTransition>;
```

## Transitions

| Transition      | From                                                      |                                                                           |
| --------------- | --------------------------------------------------------- | ------------------------------------------------------------------------- |
| `opacity`       | [`content-transition`](/react/content-transition)         | SwiftUI's default for `Text`. The whole label crossfades.                 |
| `interpolate`   | [`content-transition`](/react/content-transition)         | A crossfade that also eases colour, size and weight.                      |
| `identity`      | [`content-transition`](/react/content-transition)         | The text swaps.                                                           |
| `numericText()` | [`content-transition`](/react/content-transition)         | Changed characters blur, shrink and roll.                                 |
| `text`          | [`family`](/react/family)                                 | Family's wallet. Characters both strings share slide over, the rest fade. |

Text splits into graphemes with `Intl.Segmenter`, so emoji and accented letters move as one.

## Props

| Prop         | Type                                           | Default                                    |
| ------------ | ---------------------------------------------- | ------------------------------------------ |
| `children`   | `string`                                       |                                            |
| `transition` | One of the transitions above                   | `opacity`                                  |
| `animation`  | `"smooth"`, `"snappy"`, `"bouncy"` or a spring | `"smooth"`, or Family's spring for `text`  |

`animation` sets what follows SwiftUI's `Animation`: the width, the characters that slide over, and crossfades. Every other prop goes to the `span` it renders.
