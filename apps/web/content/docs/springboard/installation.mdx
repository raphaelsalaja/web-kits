Install `@web-kits/springboard` with your package manager of choice.

<Tabs items={[
  { label: "npm", value: "npm install @web-kits/springboard" },
  { label: "yarn", value: "yarn add @web-kits/springboard" },
  { label: "pnpm", value: "pnpm add @web-kits/springboard" },
  { label: "bun", value: "bun add @web-kits/springboard" },
]} />

## Entry Points

| Import                         |                                                                                         |
| ------------------------------ | --------------------------------------------------------------------------------------- |
| `@web-kits/springboard`        | `origin`, its effects, springs, presets, timing curves, corners and screen transitions. |
| `@web-kits/springboard/react`  | `useOrigin`.                                                                            |
| `@web-kits/springboard/motion` | Every preset as a Motion transition.                                                    |
